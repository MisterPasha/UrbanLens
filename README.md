# UrbanLens

Business Location Intelligence platform utilising Python, SQL, dbt, PostgreSQL/PostGIS (Neon), AWS (S3, Lambda and CodeBuild), FastAPI, React, TypeScript, Docker and GitHub Actions.

A Data Engineering project focused on extracting data from multiple public sources, building reliable ETL/ELT pipelines, and integrating cloud services, spatial databases and APIs to support location analysis. The initial scope covers hospitality businesses in Brighton & Hove.

Currently in development.

Data refreshes monthly.
