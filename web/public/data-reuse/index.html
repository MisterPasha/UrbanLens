Data reuse

Development preview: no UrbanLens data bundle is published yet. Public dataset publication remains pending.

The planned offer is a free, complete, versioned machine-readable copy of the publicly used derived database, with schemas, source notices, licences and checksums. Immutable CSV/GeoJSON bundles will be linked from this page and UrbanLens GitHub Releases after validation. Application code and a paginated API are not substitutes for that offer.

The merged venue database is treated as an ODbL 1.0 derivative database. Contents retain their applicable source rights. This page does not claim that rights compatibility or downloadable bundles have been cleared for public release.
